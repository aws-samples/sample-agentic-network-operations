# PSR Register

This is a synthetic fixture for testing only. It must not be replaced with or
combined with live Priority Services Register data.

Real PSR data can identify vulnerability or support needs and may include
special-category personal data. A production implementation requires privacy
and legal review, data minimisation, least-privilege access, encryption, audit
logging, retention controls, and an assessment of the relevant UK GDPR
obligations before any data is processed.

Copy the synthetic fixture into the PSR lookup Lambda package only when it is
regenerated for this demonstration.
